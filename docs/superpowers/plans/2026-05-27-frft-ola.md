# FrFT OLA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace FrFTTransform's non-overlapping block processing with a windowed overlap-add (OLA) scheme to eliminate per-frame click artifacts.

**Architecture:** Use 50% overlap (hop_size = frame_size // 2) with a sqrt-Hann analysis/synthesis window. Forward extracts overlapping frames, windows them, then calls `_frft_1d` per frame; inverse calls `_ifrft_1d`, multiplies by the synthesis window, and overlap-adds into the output buffer. The sqrt-Hann satisfies COLA at 50% overlap so the OLA normalization is 1.0 everywhere — no explicit divide step needed.

**Tech Stack:** Python, NumPy (`np.hanning` for sqrt-Hann), existing `_frft_1d`/`_ifrft_1d` helpers (unchanged), pytest.

### Task 3: Implement `FrFTTransform.forward` with OLA

**Files:**
- Modify: `src/chorus/transforms.py:145-173`

The forward pass zero-pads the signal by `hop_size` on the left so the first frame is centered on sample 0, and by enough on the right to cover all samples. `n_frames = ceil(n_samples / hop_size)` frames are extracted at stride `hop_size`. Each is windowed with the **periodic** sqrt-Hann window before the FrFT.

**IMPORTANT:** Use the periodic Hann formula `0.5 - 0.5 * cos(2πn/N)` (NOT `np.hanning(N)` which is symmetric `0.5 - 0.5 * cos(2πn/(N-1))`). The periodic form satisfies COLA at 50% overlap exactly (`hann[n] + hann[n+H] = 1`); the symmetric form deviates by ~1/N, breaking round-trip at `atol=1e-10`.

- [ ] **Step 1: Replace the `forward` method**

```python
def forward(self, stereo: np.ndarray) -> TransformRepresentation:
    stereo = _validate_stereo(stereo)
    n_samples = stereo.shape[0]
    N = self.frame_size
    H = self.hop_size
    window = np.sqrt(0.5 - 0.5 * np.cos(2 * np.pi * np.arange(N) / N))

    n_frames = math.ceil(n_samples / H)
    total_length = (n_frames - 1) * H + N

    padded = np.zeros((total_length, 2), dtype=np.float64)
    padded[H : H + n_samples, :] = stereo

    out = np.empty((2, n_frames, N), dtype=complex)
    for ch in range(2):
        for i in range(n_frames):
            start = i * H
            out[ch, i] = _frft_1d(window * padded[start : start + N, ch], self.order)

    return TransformRepresentation(
        data=out,
        original_shape=stereo.shape,
        metadata={
            "transform": "frft",
            "order": self.order,
            "frame_size": N,
            "hop_size": H,
            "window": "sqrt_hann",
            "experimental": True,
        },
    )
```

### Task 4: Implement `FrFTTransform.inverse` with OLA

**Files:**
- Modify: `src/chorus/transforms.py:175-189`

The inverse applies `_ifrft_1d` per frame, takes the real part, multiplies by the synthesis window (same periodic sqrt-Hann), and overlap-adds into a buffer at stride `hop_size`. Because periodic sqrt-Hann at 50% overlap satisfies COLA exactly, no explicit normalization divide is needed.

**IMPORTANT:** Use `np.sqrt(0.5 - 0.5 * np.cos(2 * np.pi * np.arange(N) / N))` — same periodic formula as `forward`. Do NOT use `np.hanning(N)`.

- [ ] **Step 1: Replace the `inverse` method**

```python
def inverse(self, representation: TransformRepresentation) -> np.ndarray:
    n_samples = representation.original_shape[0]
    N = self.frame_size
    H = self.hop_size
    window = np.sqrt(0.5 - 0.5 * np.cos(2 * np.pi * np.arange(N) / N))

    n_frames = representation.data.shape[1]
    total_length = (n_frames - 1) * H + N

    buf = np.zeros((total_length, 2), dtype=np.float64)
    for ch in range(2):
        for i in range(n_frames):
            start = i * H
            frame = _ifrft_1d(representation.data[ch, i], self.order).real
            buf[start : start + N, ch] += window * frame

    return buf[H : H + n_samples, :]
```

def inverse_components(
    self, components: np.ndarray, original_shape: tuple[int, int]
) -> np.ndarray:
    N = self.frame_size
    H = self.hop_size
    representation = TransformRepresentation(
        data=components,
        original_shape=original_shape,
        metadata={
            "transform": "frft",
            "order": self.order,
            "frame_size": N,
            "hop_size": H,
            "window": "sqrt_hann",
            "experimental": True,
        },
    )
    return self.inverse(representation)
